### 2.2 "主页"页签功能组

#### 功能组规则
- 功能组按 **任务** 归类，不按模块归类
- 主命令使用 **大按钮**（图标+文字，~48px 高）
- 次要命令收进 **组内下拉菜单**
- 每组之间有竖线分隔

#### 分组明细

**组 1：连接/测量**
| 按钮 | 类型 | 说明 |
|------|:----:|------|
| 在线 | 大按钮 | 切换在线/离线状态 |
| 启动 | 大按钮 | 启动测量 |
| 停止 | 大按钮 | 停止测量 |
| 通道 | 大按钮+下拉 | 通道配置（波特率、采样点等） |

**组 2：数据库**
| 按钮 | 类型 | 说明 |
|------|:----:|------|
| DBC 导入 | 大按钮 | 导入 DBC 数据库文件 |
| LDF 导入 | 大按钮 | 导入 LDF 数据库文件 |
| ARXML 导入 | 大按钮 | 导入 ARXML 数据库文件 |

**组 3：报文**
| 按钮 | 类型 | 说明 |
|------|:----:|------|
| 报文发送 | 大按钮 | 打开报文发送面板 |
| 报文监控 | 大按钮 | 打开报文监控面板 |
| 曲线 | 大按钮 | 打开/聚焦图形曲线面板 |

**组 4：记录与回放**
| 按钮 | 类型 | 说明 |
|------|:----:|------|
| 记录器 | 大按钮 | 打开记录器设置 |
| 开始记录 | 大按钮 | 开始录制 CAN 流量 |
| 停止记录 | 大按钮 | 停止录制 |
| 数据回放 | 大按钮 | 打开数据回放面板 |

**组 5：诊断**
| 按钮 | 类型 | 说明 |
|------|:----:|------|

### 2.3 "文件" — Backstage 后台视图

点击"文件"页签时，整个 Ribbon 功能区区域切换为全宽 Backstage 面板，左侧为菜单列表，右侧为对应内容：

```
┌──────────────────────────────────────────────────────────────┐
│  [← 返回]                                       CanScope     │
├────────────────┬─────────────────────────────────────────────┤
│  新建           │                                             │
│  打开           │   右侧内容区（根据左侧选中项变化）           │
│  保存           │                                             │
│  另存为         │   - 新建：显示工程模板选择                  │
│  导入           │   - 打开：显示最近工程列表                  │
│  导出           │   - 选项：显示应用设置                      │
│  选项           │                                             │
│  退出           │                                             │
├────────────────┴─────────────────────────────────────────────┤
```

**菜单项：**
- 新建 — 创建新工程
- 打开 — 打开已有工程
- 保存 / 另存为
- 导入 — ASC/CSV/BLF/DBC 等
- 导出 — ASC/CSV/BLF 等
- 选项 — 应用设置（语言、主题、数据目录等）
- 退出

## 3. 可停靠窗口工作区

### 3.1 面板列表

| 面板 ID | 名称 | 默认位置 | 默认可见 | 说明 |
|---------|------|:------:|:------:|------|
| `dbc-tree` | DBC 信号树 | 左侧 | ✅ | DBC 数据库浏览器，信号绑定 |
| `signal-decode` | 信号解析 | 左侧 | ✅ | 当前选中帧的信号解析详情 |
| `frame-monitor` | 报文监控 | 中央 | ✅ | 虚拟滚动报文表 + 变化字节高亮 + 自定义列 |
| `chart` | 图形曲线 | 底部 | ✅ | uPlot 多信号曲线 |
| `message-send` | 报文发送 | 右侧 | ❌ | Mock 报文发送面板 |
| `statistics` | 统计信息 | 右侧 | ❌ | 总线负载/帧频率/错误统计 |
| `log` | 日志 | 底部 | ❌ | 应用日志输出 |
| `filter` | 滤波 | 顶部（可停靠） | ❌ | CAN ID + 时间范围 + 信号条件过滤 |

### 3.2 停靠行为
- 每个面板标题栏支持 **拖拽**，可自由停靠（上下左右 + 标签组合）
- 面板支持 **自由关闭和打开**（通过"视图"页签或右键菜单）
- 浮动面板使用独立的弹出窗口（非 `position: fixed`，使用 Tauri WebviewWindow）
- 标签组合：同一停靠区域可有多面板以 Tab 切换

### 3.3 报文监控表特殊要求
- **虚拟滚动**：只渲染可视行（已实现，需保留）
- **可自定义列**：右键表头 → 选择显示/隐藏列
- **变化字节自动高亮**：相邻两帧相比，变化的字节用不同背景色闪烁提示

### 3.4 底部状态栏
常驻显示（始终可见，不参与停靠）：

| 字段 | 说明 |
|------|------|
| 总线负载率 | 百分比 + 进度条 |
| 错误帧 | 错误帧计数 |
| 接收帧/发送帧 | 帧计数器 |
| 总线状态 | 在线/离线/错误 指示灯 |

## 4. 布局持久化

### 4.1 数据结构

```typescript
interface LayoutConfig {
  name: string;                          // 布局名称："默认" | "分析" | "调试" | 自定义
  panels: PanelDockConfig[];             // 各面板的停靠配置
  floatWindows: FloatWindowConfig[];     // 浮动窗口位置/尺寸
  activeRibbonTab: string;               // 当前选中的 Ribbon 页签
}

interface PanelDockConfig {
  panelId: string;                       // 面板 ID
  visible: boolean;                      // 是否可见
  dockGroup: string;                     // 所属停靠组
  position: 'left' | 'right' | 'top' | 'bottom' | 'center' | 'float';
  size: number;                          // 宽度/高度（像素或百分比）
  tabIndex: number;                      // 在标签组中的顺序
}

interface FloatWindowConfig {
  panelId: string;
  x: number;
  y: number;
  width: number;
  height: number;
}
```

### 4.2 存储方案
- **不存前端 localStorage**，通过 Tauri IPC 存入工程文件（`.canscope`）或独立布局文件
- Rust 侧新增命令：`save_layout` / `load_layout` / `list_layouts` / `delete_layout`
- 工程级别：每个工程绑定一个布局
- 全局级别：应用启动时的默认布局

### 4.3 "视图"页签
提供布局预设管理功能：

| 按钮 | 说明 |
|------|------|
| 默认布局 | 恢复出厂默认布局（信号树左 + 报文表中 + 曲线底） |
| 分析布局 | 预设：信号树左 + 报文表中心 + 信号解析右 + 曲线底部 |
| 调试布局 | 预设：报文表最大化，其余面板收折 |
| 保存当前布局 | 保存为命名布局 |
| 管理布局 | 重命名/删除已有布局 |

### 4.4 验收标准
- 拖拽面板改变位置后，保存工程 → 关闭应用 → 重新打开 → **布局完整恢复**（包括浮动窗口位置和尺寸）

## 5. 实现约束

| 约束 | 说明 |
|------|------|
| 技术栈 | 保持现有：SolidJS 1.9 + TypeScript 5.7 + TailwindCSS 4.3 + Vite 6 + Tauri 2 |
| 停靠库 | 自建（SolidJS 生态无成熟停靠库，dockview/golden-layout 均依赖 React） |
| 硬件逻辑 | **不实现任何真实 CAN 硬件逻辑**，用 Mock 数据填充展示即可 |
| 文件结构 | 保持现有目录结构，只重构 UI 层 |
| 设计规范 | 严格遵循 `docs/design/design.md` 中的设计系统（颜色/字体/间距/组件） |
| 现有组件 | 尽量复用：FrameTable（虚拟滚动）、SignalTree、SignalChart（uPlot） |

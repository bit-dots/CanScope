## 1. 功能概述

数据回放模块允许用户导入一个或多个 CAN 日志文件（ASC / CSV / BLF / TRC），以停靠面板的形式进行多文件串联回放，将报文按时间顺序统一输出到报文监控窗口。

### 1.1 设计原则

- **停靠面板**：与报文监控、资源管理器等面板一致，支持浮动、最小化、最大化、关闭、弹出
- **串联拼接**：多文件首尾相连无间隙（模型 B），不按绝对日历时间插入空档
- **统一时间线**：不按 bus_id 区分，所有文件统一时间顺序输出
- **自动排序**：导入文件时按原始时间戳 `start_time` 升序排列

## 3. 播放控制

### 3.1 播放 / 暂停 / 停止

| 属性 | 说明 |
|------|------|
| 状态 | ✅ 已实现 |
| 描述 | 面板控制栏提供 ▶ 播放、⏸ 暂停、■ 停止 三个按钮，与状态栏 / Ribbon 快捷按钮共享同一后端引擎 |

### 3.3 倍速控制

| 属性 | 说明 |
